## [1.2.0] - 2026-08-27

### Changed
- Complete modern visual redesign: Pitch black palette (\`#09090b\`), subtle glassmorphism cards, and electric indigo/cyan accent glows.
- Standardized Lucide React iconography across sidebar navigation and quick access cards.
- Enhanced layout breathing room, improved typography hierarchy, and smoother card hover elevations.

### Fixed
- Fixed high-contrast text readability across muted description badges.
- Resolved build and asset chunk resolution warnings in Vite production compiler.

---

## [1.1.0] - 2026-05-15

### Added
- Interactive Campus Transit Hub with simulated real-time GPS shuttle tracking.
- Food Court digital ordering interface with stall filtering, daily specials, and pickup token generation.
- Digital Library reservation system with shelf location mapping.
- Career Hub placement eligibility predictor based on CGPA and technical skillset.

## [1.0.0] - 2026-01-10

### Added
- Initial release of the Uni-Verse university campus web platform.
- Central student dashboard with course timetable, attendance metrics, and profile card.
- Client-side routing with React Router DOM.
- Responsive mobile drawer navigation and campus quick links.
