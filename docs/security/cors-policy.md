# Cross-Origin Resource Sharing (CORS) Policy

## Policy Details
- Production domain whitelist:
  - `https://uni-verse-swart.vercel.app`
  - `https://universe.campus.internal`
- Allowed HTTP Methods: `GET`, `POST`, `PUT`, `PATCH`, `DELETE`, `OPTIONS`
- Allowed Headers: `Authorization`, `Content-Type`, `X-Requested-With`
- Pre-flight max age cache set to 86400 seconds (24 hours).
