# Hostel Management & Maintenance API

## Overview
Facilitates hostel block allotments, leave pass requests, and maintenance ticket submissions.

### Endpoints

#### GET /api/v1/hostel/room
Retrieves assigned block, room number, roommate information, and warden contact.

#### POST /api/v1/hostel/maintenance-tickets
Submits an electrical, plumbing, or internet repair ticket.
