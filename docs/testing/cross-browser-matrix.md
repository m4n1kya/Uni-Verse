# Cross-Browser & Viewport Compatibility Matrix

## Supported Targets
- **Desktop Browsers**:
  - Chrome / Chromium (Latest 2 versions)
  - Firefox (Latest 2 versions)
  - Safari (16+)
  - Microsoft Edge (Latest 2 versions)
- **Mobile Viewports**:
  - iPhone 13/14/15 (iOS Safari)
  - Pixel 7/8 (Chrome Android)
  - Samsung Galaxy S22/S23 (Samsung Internet)
