# WCAG 2.1 AA Accessibility Audit Checklist

## Verification Checklist
- [x] Color contrast ratio meets minimum 4.5:1 for normal text and 3:1 for large text.
- [x] All icon buttons possess explicit `aria-label` attributes.
- [x] Interactive dialogs trap focus and respond to Escape key dismissal.
- [x] Form controls have associated `<label>` elements.
- [x] Screen readers correctly pronounce status changes via `aria-live="polite"`.
